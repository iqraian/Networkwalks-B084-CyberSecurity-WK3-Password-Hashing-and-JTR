## 🔍 Key Concepts Learned

### 1. Password Hashing

- Passwords are processed through hashing algorithms to produce fixed-length hash values.
- Hashing is designed to be a one-way process.
- A hash does not directly reveal the original password.

### 2. Hash Identification

- Explore different hash formats and their characteristics.
- Understand why identifying the correct hash type matters during password auditing.

### 3. John the Ripper (JTR)

- Introduction to John the Ripper.
- Understanding its role in password security auditing.

## 💡 Key Takeaways

- Hashing and encryption are different concepts.
- A hash is not designed to be reversed directly.
- Weak passwords are more vulnerable to dictionary and brute-force attacks.
- Strong password policies improve account security.
- Secure password storage requires appropriate password-hashing algorithms, salts, and work factors.
